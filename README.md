# taocp

Working through Knuth's *The Art of Computer Programming*, Volumes 1–4B:
exercise answers in Markdown, algorithms in Odin, and a record of what was
learned. The exercise statements and Knuth's answers are in the books; this
repository only references them.

* `PLAN.md`: goal, decisions, milestones (one per chapter)
* `PROGRESS.md`: proficiency per topic
* `AGENTS.md`: coding and working rules
* `knuth/`: answers, by section
* `exercises/`: lessons chapters built around a topic

`./build.sh test` runs every test.
